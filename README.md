# Smaran Raut - SEO Specialist & Web Developer Website

High-performance, semantic SEO-optimized website architecture built for **Smaran Raut**, based in Itahari, Sunsari, Koshi Province, Nepal.

## 🚀 Overview

- **Sector:** Search Engine Optimization & Web Development
- **Location:** Itahari, Sunsari, Koshi Province, Nepal
- **Architecture:** Zero-white-screen static pre-rendered HTML/CSS/JS with zero dependency bloat.
- **Speed & Vitals:** 100/100 Core Web Vitals standard, lightweight CSS variables, instant touch navigation.
- **Topical Authority:** Full topical coverage with 6 core practice vertical clusters and 28 in-depth knowledge guides.
- **Compliance:** Aligned with Office of the Company Registrar (OCR) and Inland Revenue Department (IRD) statutory guidelines in Nepal.

## 🛠️ Local Usage

You can open `index.html` directly in any modern browser without needing a build step or server. Alternatively, run any local static HTTP server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```
