How to Fix Cumulative Layout Shift (CLS)

Featured Snippet: Direct Technical Answer

Eliminate CLS by always declaring explicit width and height attributes or CSS aspect-ratio on all images and embeds, reserving static min-height containers for dynamic banners or ads, and preventing FOIT/FOUT using CSS font fallback metric overrides.

Master Practice Architecture

This technical guide is an educational component of our core practice on Core Web Vitals & Page Speed Engineering. Explore our full speed optimization framework and interactive bounce rate simulator.

Visit Core Web Vitals Practice →

1. Aspect Ratios for Images and Embedded Media

When an image tag lacks explicit dimensions, the browser renders it with 0 height initially, then violently jumps the text down once the binary image loads. Declaring aspect-ratio: 16 / 9; or setting HTML width and height attributes reserves exact vertical space before download finishes.

2. Font Fallback Metrics & size-adjust

When web fonts swap from system Arial or Times New Roman, letter spacing differences cause text paragraphs to re-wrap. Using CSS size-adjust, ascent-override, and descent-override matches the system fallback font to the web font dimensions, achieving a perfect 0.00 CLS score.

3. Dynamic Ads and Dynamic Embed Containers

Never allow third-party scripts to inject ad slots or interactive widgets without reserving a pre-allocated wrapper with min-height. Pre-sizing container elements ensures user reading flow is never interrupted by viewport jumping.

Eliminating Annoying Layout Jumps with Website Speed Optimization

Unexpected layout shifts frustrate readers, cause accidental clicks, and trigger ranking penalties under Google's page experience guidelines.
